# scikit-learn Cookbook — Chapters 1–8

**Book:** *scikit-learn Cookbook, Third Edition: Over 80 recipes for machine learning in Python with scikit-learn*  
**Author:** John Sukup  
**Publisher:** Packt Publishing, 2025

This repository documents code reproduction, short theoretical notes, and direct interpretations for the first five chapters of the book. Each notebook can be opened in Google Colab and contains saved execution results.

## Chapter overview

| Chapter | Main material |
|---|---|
| 1. Common Conventions and API Elements of scikit-learn | Estimators, transformers, custom classes, pipelines, attributes and tuning |
| 2. Pre-Model Workflow and Data Preprocessing | Imputation, scaling, encoding, pipelines and feature engineering |
| 3. Dimensionality Reduction Techniques | PCA, LDA, t-SNE and practical comparisons |
| 4. Building Models with Distance Metrics and Nearest Neighbors | Distance metrics, KNN, tuning and evaluation |
| 5. Linear Models and Regularization | Linear regression, Ridge, Lasso, ElasticNet and model comparisons |

## How to run

Open the relevant `.ipynb` file in [Google Colab](https://colab.research.google.com/). Select **Runtime → Run all** if you need to re-execute the notebook. Results may differ slightly across dependency versions, cross-validation partitions or stochastic algorithms.
